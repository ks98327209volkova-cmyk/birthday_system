# Birthday System

Микросервисное приложение для управления подарками и автоматическими напоминаниями о днях рождения.

## Описание системы

Система состоит из двух микросервисов:

1. **Gift Manager** - основной сервис для работы с данными. Отвечает за хранение информации о людях, их днях рождения, идеях подарков и истории подарков.

2. **Notification Service** - сервис уведомлений. Получает события из Kafka, рассчитывает напоминания о приближающихся днях рождения (за 30, 14 и 7 дней) и хранит их в Redis. Хранит только напоминания текущего месяца.

## Технологический стек

- **Язык**: Go 1.24
- **Базы данных**: PostgreSQL (основное хранилище), Redis (кеш напоминаний)
- **Межсервисное взаимодействие**: Kafka (события)
- **API**: REST через gRPC Gateway
- **Документация**: Swagger (только для gift-manager)
- **Тестирование**: testify + mockery

## Быстрый запуск

```bash
docker-compose build 
docker-compose up -d
```

После запуска будут доступны:
- Gift Manager на порту 8080
- Notification Service на порту 8081
- Kafka на порту 8082

## API сервисов

### Gift Manager (порт 8080)

```
Основные операции с людьми:
POST   /v1/person/add              - добавить нового человека
GET    /v1/person/{id}             - получить информацию о человеке
PUT    /v1/person/{id}             - обновить данные человека
DELETE /v1/person/{id}             - удалить человека
GET    /v1/persons                 - получить список всех людей

Идеи подарков:
POST   /v1/person/{id}/gift-ideas  - добавить идею подарка
GET    /v1/person/{id}/gift-ideas  - получить идеи подарков
DELETE /v1/person/{id}/gift-ideas/{idea_id} - удалить идею подарка

История подарков:
POST   /v1/person/{id}/gift-history - добавить запись о подарке
GET    /v1/person/{id}/gift-history - получить историю подарков
```
**Документация API:** http://localhost:8080/docs/index.html

### Notification Service (порт 8081)

```
Напоминания:
GET /v1/reminders   - получить все напоминания на текущий месяц
```

## Примеры использования

### Добавление человека

```bash
curl -X POST http://localhost:8080/v1/person/add \
  -H "Content-Type: application/json" \
  -d '{
    "person": {
      "name": "Иван Иванов",
      "birthday": "1990-05-15",
      "category": "family"
    }
  }'
```

### Получение напоминаний

```bash
curl http://localhost:8081/v1/reminders
```

### Система событий

Через Kafka передаются 4 типа событий:
- `person_added` - при добавлении нового человека
- `person_updated` - при изменении данных человека
- `person_deleted` - при удалении человека
- `monthly_reminder` - 1 числа каждого месяца для пересчета напоминаний

### Хранение напоминаний

- Напоминания хранятся только для текущего месяца
- Ключ в Redis: `ГГГГ-ММ:personID:days` (пример: `2024-05:123:30`)
- 1 числа каждого месяца Redis полностью очищается и напоминания пересчитываются
- Поддерживаются напоминания за 30, 14 и 7 дней до дня рождения

### Категории людей

Поддерживаются три фиксированные категории:
- family - члены семьи
- friends - друзья
- colleagues - коллеги
